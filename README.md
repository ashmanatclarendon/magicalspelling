# Magical Spelling

Watch the word, remember it, spell it. Fill the cauldron.

## Publish on GitHub Pages
1. Create a new public repository (e.g. `magical-spelling`).
2. Upload **all** files from this zip (they all sit at the top level - no folders).
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, folder `/ (root)` → Save.
4. Open the link on your phone → Share → **Add to Home Screen**.

## Updating
After changing any file, edit `sw.js` and bump `VERSION` (e.g. `ms-v2`) so phones fetch the new version.

## Testing the Easter egg
Add `?frog` or `?frogprince` to the end of the URL.
